Which folders might be blocked?

Browsers protect broad and sensitive locations. If a folder is refused, choose a more specific folder inside it instead.

● macOS

Chrome or Edge may block the startup-disk root, your entire Home folder, /System, and Library folders such as /Library or ~/Library.

macOS may also show its own permission prompt for Desktop, Documents, Downloads, iCloud Drive, or external volumes.

⊞ Windows

Chrome or Edge may block drive roots such as C:\, the whole user-profile folder, and protected system locations such as the Windows directory.

Windows security controls, organization policies, or another account’s private folders can block additional locations.

Good choices include a specific Pictures, Videos, Downloads, or project subfolder that you own.
